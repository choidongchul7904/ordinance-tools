## 공유 스펙 계약 (2026-10-12, uian·format·yego 합의 — 하위호환 추가)
- **`유형`** ∈ {`제정`,`일부개정`,`전부개정`}. 판별 규칙(`scripts/ordtype.py` `detect_type`, yego에 동일 사본 인라인):
  제명 공백 제거 후 `전부개정`→전부개정 / `일부개정` 포함 또는 `개정조례안`·`개정규칙안`으로 끝남→일부개정 / 그 밖→제정.
  명시 `유형`이 이기되, 제명 유형이 제정이 아닌데 명시 유형과 다르면 **충돌 → 빌더 중단**.
- **개정조례**: `현행조례명`(str, 「」 없음) + `개정문`(obj[] `{level,text}`) = **두문 다음 줄부터** 지시문·신설 본문.
  두문 줄은 넣지 않는다 — 빌더가 `현행조례명`+`유형`으로 생성. `본칙`은 하위호환으로 `개정문`과 같게 둘 수 있다.
- **level**: `장`·`절`(제목, 독립 항목) + `조`·`항`·`호`·`목`·`1)`·`가)`·`(1)`·`(가)`. 개정문의 지시문 줄은 `조`.
- 자리표시자: 빈 `소관위원회`·`문의처`는 `○` 표시로 찍고 `_미확정`/WARN으로 보고한다(가짜 실번호 금지).

## 종료 코드
- `run_suite.py`: 0 = 전부 OK/WARN · 1 = 서식 하나 이상 실패 · 2 = 실행 전 중단(유형 충돌, `--only` 미지 이름/0개).
- `fetch_current.py`: 기본 **엄격** — 지시문 미반영(적용 오류·해석 불가·G2 미반영)·조회 실패 시 1, spec 미저장.
  `--lenient`면 실패 자리에 `[[TODO:적용실패 …]]` 행을 넣고 0(G3가 빌드를 막음).
- `parse_ordinance.py`: 조문/개정문을 못 찾거나 유형 충돌이면 SystemExit(≠0).
