# 통합 스펙(suite.json) 스키마

4개 빌더가 공유하는 단일 입력이다. `parse_ordinance.py`가 조례안 파일에서 만들고,
빠진 값은 사람이 채운다.

## 공통

| 키 | 타입 | 필수 | 쓰는 서식 | 설명 |
|---|---|---|---|---|
| `조례명` | str | ● | 4종 전부 | 「」 없이. 파일명에도 쓰인다 |
| `유형` | str | ● | 입법예고 | `제정`·`일부개정`·`전부개정` (조례명에서 자동 판별) |
| `공포기관` | str | | 완성본·표준서식·입법예고 | 공포번호행 접두 — `경기도`, `경기도교육청` 등 |
| `의회명` | str | | 입법예고 | 공고·예고문의 발령 기관. 미지정 시 `경기도의회`(서식 배포 기관) |
| `대표발의` | str | ● | 완성본·입법예고·서명부 | 성명만(직함 없이) |
| `발의연월일` | str | | 완성본 | `2026년 08월    일` 형태. 미정이면 빈칸형 |
| `발의자` | str | | 완성본 | 표지 표의 발의자 칸 |
| `소관위원회` | str | | 입법예고 | 예고문의 `○○○위원회` |

## 제안설명서

| 키 | 타입 | 쓰는 서식 | 설명 |
|---|---|---|---|
| `제안이유` | str[] | 완성본·입법예고 | 문단 단위. 입법예고 서식은 `가. 나. 다.` 항목 체계이므로 산문이면 항목화 검토 |
| `주요내용` | str[] | 완성본·입법예고 | 각 항목 끝에 `(안 제○조)` 근거 표기 |
| `참고사항` | str[] | 완성본 | 가.관계법령 나.입법예고 다.비용추계서 라.검토의견 마.예고결과. 생략 시 빈칸형 기본값 |

값이 비면 빌더가 자리표시자로 덮어쓰고 경고를 낸다(서식 예시 내용이 제출본에
남는 것을 막기 위해서다).

## 조문

```json
"본칙": [{"level": "조", "text": "제1조(목적) 이 조례는 …"}],
"부칙": [{"level": "조", "text": "제1조(시행일) 이 조례는 공포한 날부터 시행한다."}]
```

`level`은 `조·항·호·목·1)·가)·(1)·(가)` 8단계. **앞 공백은 빌더가 서식별로 붙이므로
넣지 않는다.** `text`에는 번호·기호(제1조, ②, 1., 가.)를 포함한다.

## 입법예고 전용

| 키 | 타입 | 설명 |
|---|---|---|
| `공고번호` | str | `제2026-100호` |
| `공고일` | str | `2026. 08. 20.` |
| `제출기한` | str | `2026년 9월 3일(목)까지` |
| `문의처` | str | `○○○과 000)0000-0000` — 부서·전화만. 앞의 의회명은 빌더가 붙인다 |
| `관계법령` | obj[] | `[{"법령명":"고등교육법","조문":[{"level":"조","text":"…"}]}]` |

### 개정조례일 때 추가 필수

| 키 | 타입 | 설명 |
|---|---|---|
| `현행조례명` | str | 「」 없이. 개정 두문 `「○○ 조례」 일부를 다음과 같이 개정한다.`에 쓰인다 |
| `개정문` | obj[] | 개정 지시문(`제○조제○항 중 “…”를 “…”로 한다.`). 없으면 `본칙`을 쓴다 |
| `대비표` | [str,str][] | `[["현행 조문","개정안 조문"], …]`. 셀 안 줄바꿈은 `\n` |
| `현행조례` | obj[] | 참고 1에 실을 현행 조례 전문 — `law-search`로 조회 |

대비표 관행: 변경 없음 = `(생  략)` / `(현행과 같음)`, 자구 수정은 바뀐 부분만 쓰고
나머지는 줄표(`----`), 신설은 `<신  설>` / 새 조문 전문.

## 서명부 전용

| 키 | 타입 | 설명 |
|---|---|---|
| `공동발의` | str[] \| obj[] | `"수원1\|김철수"` 또는 `{"소속":"수원1","성명":"김철수"}` |
| `서명부쪽수` | int | 미지정 시 인원수로 자동 산정(15명/쪽, 인원 0이면 2쪽) |

서명 열은 손서명용이라 **항상 공란**이다.

## 메타

| 키 | 설명 |
|---|---|
| `_미확정` | 파서가 못 채운 항목 목록 — 사용자에게 한 번에 모아 묻는 근거 |
| `_원본` | 스펙을 뽑아낸 원본 파일 경로 |
