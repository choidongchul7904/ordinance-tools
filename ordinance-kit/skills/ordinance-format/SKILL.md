# 조례 표준 서식 HWPX (ordinance-format)

법령 입안 실무의 「조례만들기(서식)」 가이드 규격을 그대로 구현한 스킬.
한글(HWP) COM으로 **정품 저장**하므로 재패키징·네임스페이스 후처리가 필요 없고,
한글 보안수준 '높음'에서도 경고 없이 열린다.

## 서식 규격

| 요소 | 서식 |
|---|---|
| 공포번호행 | `○○시·도(시·군·구)조례  제        호` — 신명조 14pt, 왼쪽 |
| 제명 | 가운데 정렬, 신명조 16pt, **진하게** |
| 본칙 조문 | 신명조 14pt, 양쪽정렬, 첫 줄 내어쓰기 |
| 부칙 제목 | `부      칙` (부+공백6+칙) — 가운데, 14pt, **진하게** |

**조·항·호·목 내어쓰기 7단계** (앞 공백은 스크립트가 자동 부여):

| 레벨 키 | 예 | 앞 공백 | 내어쓰기 |
|---|---|---|---|
| `조` | 제1조(목적) ① … | 0칸 | 14pt |
| `항` | ② … | 2칸 | 14pt |
| `호` | 1. … | 2칸 | 24.4pt |
| `목` | 가. … | 4칸 | 45.4pt |
| `1)` | 1) … | 6칸 | 54.2pt |
| `가)` | 가) … | 8칸 | 75.2pt |
| `(1)` | (1) … | 10칸 | 87.8pt |
| `(가)` | (가) … | 12칸 | 108.8pt |

> ※ `(가)` 108.8pt는 원본 가이드 PDF에서 수치가 잘려 있어 동일 유형 간 +21pt
> 등차 패턴(1.→가., 1)→가) 모두 +21pt)으로 추정한 값. 기관 확정 기준이
> 다르면 `scripts/build_ordinance.py`의 `LEVELS`만 고치면 된다.

## 사용법

### A. 빈 서식 템플릿 요청 ("조례 서식/템플릿 만들어줘")

```bash
python scripts/build_ordinance.py --template "출력경로.hwpx"
```

검증 완료된 `assets/ordinance-template.hwpx`를 복사한다(COM 불필요, 즉시 완료).
템플릿은 2쪽 구성 — 1쪽 조례안 골격(공포번호행·제명·본칙·부칙), 2쪽 내어쓰기
기준표(각 단계가 실제 문단 서식으로 적용된 견본. 복사해 쓰면 서식 유지).

### B. 조문 내용을 표준 서식으로 조판

spec JSON을 만들어 실행한다:

```bash
python scripts/build_ordinance.py spec.json
```

```json
{
  "output": "출력폴더\\경기도_○○_조례안.hwpx",
  "title": "경기도 ○○ 지원 조례안",
  "promulgation_line": "경기도조례  제        호",
  "body": [
    {"level": "조", "text": "제1조(목적) 이 조례는 …함을 목적으로 한다."},
    {"level": "조", "text": "제2조(정의) ① 이 조례에서 사용하는 용어의 뜻은 다음과 같다."},
    {"level": "호", "text": "1. \"○○\"란 …를 말한다."},
    {"level": "목", "text": "가. …"},
    {"level": "항", "text": "② …"}
  ],
  "addenda": [
    {"level": "조", "text": "제1조(시행일) 이 조례는 공포한 날부터 시행한다."}
  ]
}
```

- 각 항목의 `text`에는 번호·기호(제1조, ②, 1., 가. 등)를 **포함해서** 쓴다.
  앞 공백은 레벨에 따라 스크립트가 자동으로 붙이므로 넣지 않는다.
- `promulgation_line` 생략 시 기본값 `○○시·도(시·군·구)조례  제        호`.
- `addenda`가 있으면 `부      칙` 제목이 자동 삽입된다.
- `"pdf_preview": true`를 넣으면 같은 이름의 확인용 PDF도 함께 저장된다.
- 조문 원문을 확인하지 못한 항목은 `text`에 확인 실패 사유를 문장으로 풀어 쓰지 말고
  `[원문 미확인]`/`[확인 필요]` 마커를 넣을 것. `build_ordinance.py`가 이를 감지해 완성본
  에서는 그 조항을 빈 줄로 처리하고, 원문은 stdout에 `[미검증 ...]` 목록으로만 출력한다
  (대화창 보고 전용 — 문서에는 절대 남기지 않는다). 마커 없이 쓰면 그대로 노출된다.

### 검증 (스크립트가 자동 수행, 실패 시 종료코드 1)

1. 한글 COM으로 생성 → 임시 폴더에 stage 저장 (최종 경로 직접 저장 금지 — 파일 잠금 방지)
2. stage HWPX를 zip으로 열어 header.xml 검사: 신명조 등록 여부, 사용된 내어쓰기 값 전수 확인
3. SaveAs 반환값·산출 파일 존재 확인 후 최종 경로로 복사

레이아웃이 중요한 문서(표 포함·쪽수 제한 등)는 추가로 PDF를 pypdfium2로
렌더해 육안 확인할 것 — 잘림·겹침은 텍스트 검사로 잡히지 않는다.

## 이 PC 검증 사항 (스크립트에 이미 반영됨)

- `HParameterSet` 속성 대입이 조용히 깨져 있다 — 반드시
  `CreateAction → CreateSet → GetDefault → SetItem → Execute` 경로 사용.
- CharShape의 FaceName은 `FontType*=1`(TTF)을 함께 SetItem해야 적용된다.
  신명조는 이 PC에 TTF로 존재함(header.xml에 `신명조 TTF`로 등록되는지 확인).
- COM `Open`/`SaveAs`는 실패해도 예외 없이 False만 반환 — 반환값을 반드시 검사.
- `Indentation` 음수 = 내어쓰기, 단위는 hwpunit(pt×100). `AlignType` 3 = 가운데.
- 출력 경로를 지정받지 못하면 `출력폴더`에 저장.
- 조문 내용의 기획·작성·검토가 필요하면 ordinance-draft / ordinance-review로
  넘기고, 이 스킬은 완성된 조문의 서식 조판만 담당한다.
