# 입법예고 의뢰 서식(제정조례) 정밀 명세

원본: 경기도의회 법제과 배포 `★250812입법예고 의뢰 서식(제정조례).hwpx` (2025-08-12판).
스킬 내장 사본: `assets/250812-ipbeop-yego-jejeong.hwpx`.
아래 문단 인덱스는 `Contents/section0.xml`의 최상위 `<hp:p>` 순번(0-based, 총 67개)이다. 내장 정본은 원 배포본의 예시 조례 내용을 `○○` 자리표시자로 비운 빈 골격이다(문단·run 개수와 서식 ID는 원본 그대로라 아래 인덱스가 유효하다).

개정조례 서식과의 차이 요약:
- 공고문 항목이 **5개**(개정판은 6개) — "신·구조문 대비표 : 붙임" 항목이 없다.
- **신·구조문 대비표 블록과 현행 조례 블록이 없다** — 전체가 3개 블록(공고문·조례안·관계법령 발췌).
- 참고 라벨이 `참 고` 하나뿐(개정판은 참고 1·참고 2), 「전부개정 시」 안내 박스도 없다(안내 박스는 2개).
- 조례안 본문이 개정 지시문이 아니라 **완성 조문(제1조~제6조+부칙)** 형식.
