# 안건 서명부 서식 정밀 명세

원본: `7. 안건 서명부_양식.hwpx` (한컴오피스 한글 12.0.0.4605 작성, 29,515 bytes)
내장본: `assets/template.hwpx` — 원본 무수정 복사본.

## 1. 문서 개요

- A4 세로 1단, 상하좌우 여백 동일(pageBorderFill offset 1417).
- **2쪽**, 두 쪽의 구성이 완전히 동일하며 연번만 이어진다(1~15 / 16~30).
- 쪽 나눔은 강제 개행이 아니라 **표가 쪽을 꽉 채워 생기는 자연 넘김**이다.
  따라서 표 행 수(16행)를 유지하는 한 쪽 경계가 흔들리지 않는다.
- 표에 `pageBreak="CELL"`, `repeatHeader="1"`이 걸려 있으나 실제로는 쪽마다
  독립 표가 있으므로 발동하지 않는다.

## 2. section0.xml 문단 인덱스

`<hs:sec>`의 직계 자식은 문단 12개. **6개가 한 쪽 블록**이다.

| idx | paraPr | 내용 | 비고 |
|----|--------|------|------|
| 0 | 12 (CENTER) | `발의의원 서명부` | charPr 8 = 24pt. **앞에 secPr+colPr를 담은 빈 run이 있음** |
| 1 | 12 (CENTER) | `(000 의원 대표발의)` | charPr 9 = 16pt |
| 2 | 11 (JUSTIFY) | (빈 줄) | |
| 3 | 14 (JUSTIFY) | `■ ` + `안건명: 000` | run 2개 — charPr 2(■) / charPr 10(본문). **2번째 run만 교체** |
| 4 | 14 | (빈 줄) | |
| 5 | 11 | `<hp:tbl>` 를 담은 문단 | 표 본체 |
| 6~11 | — | 2쪽 블록 (0~5와 동일 구성, secPr 없음) | **복제 원본으로 쓸 것** |

1쪽 첫 문단만 secPr를 갖기 때문에 run 인덱스가 쪽마다 다르다.
문단 텍스트를 고칠 때는 `hp:t`를 가진 run만 세어 슬롯을 지정해야 한다.

## 3. 표 구조

`rowCnt=16, colCnt=4, cellSpacing=0, borderFillIDRef=3, 총폭 47612 HWPUNIT`

| 열 | 머리글 | cellSz width | 채움 |
|---|---|---|---|
| 0 | `연번` | 5111 | 자동 부여 (쪽 넘겨 연속) |
| 1 | `소  속` | 18129 | 사용자 입력 |
| 2 | `의 원 명` | 12186 | 사용자 입력 |
| 3 | `서  명` | 12186 | **비워 둘 것** — 손서명란 |

- 머리글 행: borderFillIDRef 4/5(음영 있음). 데이터 행: 6/7/14/15.
- 데이터 행 높이 3404(마지막 행 3575), 셀 여백 좌우 510·상하 141.
- 모든 셀 문단은 `paraPrIDRef="12"`(가운데 정렬) + `charPrIDRef="1"`(15pt).
- **빈 셀은 `<hp:run charPrIDRef="1"/>`** 로 hp:t가 아예 없다 —
  텍스트를 넣으려면 `hp:t`를 새로 만들어 붙여야 한다.
- 빈 셀 문단은 `id="2147483648"`, 글자가 있는 셀은 `id="0"`. 무시해도 무방.

## 4. 쪽수 확장 규칙 (검증됨)

**표 행 수는 건드리지 않고, 6문단 블록을 통째로 복제한다.**

- 쪽수 = `ceil(인원수 / 15)`, 인원 미지정이면 원본대로 2쪽.
- 1쪽만 필요하면 문단 6~11을 삭제, 3쪽 이상이면 문단 6~11을 deepcopy로 append.
- 복제하면 `hp:tbl/@id`가 중복되므로 max+1로 재발급.
- 연번은 `쪽번호*15 + 행번호`로 전 쪽에 걸쳐 다시 매긴다.
- 남는 행은 소속·의원명을 빈 문자열로 두어 손서명용 빈칸으로 남긴다.

실측: 40명 → 3쪽(연번 1~45, 41~45 빈칸), 3명 → 1쪽, 0명 → 2쪽. 모두 PDF 렌더로
레이아웃 무결 확인.

## 5. 편집 시 함정

1. **`<hp:linesegarray>`(lsa)는 레이아웃 캐시다.** 글자를 바꾼 문단과, 높이가
   변할 수 있는 **표 행(tr) 전체**에서 제거해야 한다. 남기면 재저장 후 글자가
   한 줄에 겹친다. 반대로 섹션 전체를 일괄 제거하면 좁은 칸에서 줄바꿈이
   회귀한다 — 행 단위 최소 범위만.
2. **Python 재패키징본은 한/글 보안수준 '높음'에서 열리지 않는다.**
   재패키징 시 mimetype을 무압축(STORED)으로 맨 앞에 넣고, 반드시 COM
   `Open`→`SaveAs 'HWPX'`로 정품 재저장할 것.
3. **COM `Open()`은 실패해도 예외 없이 False만 반환**한다. 검사를 빠뜨리면 빈
   문서가 "성공"처럼 저장된다.
4. 최종 경로 파일을 직접 열어 재저장하면 한/글이 파일을 잡아 다음 빌드가
   `PermissionError [WinError 32]`로 실패한다. 스크래치패드에 스테이징하고
   `SaveAs`로 내보낼 것.
5. header.xml의 charPr/paraPr id는 이름표가 아니라 **위치 인덱스**다. 이 서식은
   스타일을 새로 만들 필요가 없으므로 header.xml은 건드리지 않는다.
